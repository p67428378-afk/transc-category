# Automated Transaction Categorization System

This repository contains the code for the Automated Transaction Categorization System, a full-stack application designed to automatically categorize raw bank transaction data using an LLM-based engine.

## Project Structure

- `frontend/`: Contains the React-based web dashboard.
- `backend/`: Contains the Python/FastAPI backend API.
- `etl/`: Contains the Python/Pandas ETL pipeline components.
